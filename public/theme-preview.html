Claude Terminal Hub v1.13.3 기준. ① 캐릭터 테마 7종(치이카와 4 · 동물의숲 3) ② 커서 / 메신저 입력창 시안 ③ 폰트가 안 바뀌는 원인과 개편안.
아래 버튼을 눌러가며 실제로 바뀌는 화면을 보고 고르시면 됩니다. 앱 코드는 아직 하나도 안 건드렸습니다.

0 현재 상태 진단

왜 "테마가 다 비슷"하고 "폰트가 안 바뀌는" 것처럼 느껴지는지 — 코드에서 확인한 원인.

🎨 테마 10종이 다 비슷한 이유

지금 테마가 바꾸는 건 index.html 의 CSS 변수 8개(--bg/--panel/--head/--border/--accent/--text/--muted/--ok)와 app.js 의 TERM_THEMES(xterm ANSI 16색), 그리고 커서 색뿐입니다.

  • 10종 전부 다크 개발자 팔레트 — 배경이 #0c0e14 ~ #2e3440 사이라 명도가 거의 동일
  • 레이아웃·모서리 반경·아이콘·타이포는 테마와 무관하게 완전히 동일
  • 결국 실질적으로 바뀌는 건 강조색 hue 하나 → "다 비슷"하게 느껴지는 게 당연

→ 캐릭터 테마는 색 말고 마스코트 · 커서 · 입력창 · 모서리까지 같이 바꿔야 체감이 납니다.

🔤 폰트가 일부만 바뀌는 이유 버그성

원인 3개가 겹쳐 있습니다.

  • ① 적용 범위가 터미널뿐 — applyFontFamily() 는 term.options.fontFamily 만 바꿉니다. 헤더·세션목록·탭·입력창은 CSS에 "Segoe UI" 가 하드코딩(index.html body, .compose textarea)이라 절대 안 바뀜 → "일부만 바뀐다"
  • ② 고른 폰트가 PC에 없음 — 목록의 JetBrains Mono / Fira Code / D2Coding 은 앱에 번들되어 있지 않고 로컬 설치 폰트에 의존. 없으면 조용히 Consolas 로 폴백 → 골라도 화면 그대로
  • ③ 캔버스 렌더러 글리프 캐시 — CanvasAddon 사용 중이라 폰트 교체 뒤 clearTextureAtlas() / refresh 없이는 이전 글자가 남을 수 있음

→ 6번 섹션에서 이 PC에 실제로 뭐가 깔려 있는지 자동 검사 결과를 보여드립니다.

2 캐릭터 커서 — 3안

점선 영역에 마우스를 올리면 진짜 커서가 바뀝니다. 위에서 고른 캐릭터가 그대로 반영됩니다.

3 입력창(컴포즈) 메신저화 — 3안

현재 컴포즈는 textarea + 버튼 한 줄입니다. 위에서 고른 테마 색이 아래 3안에 그대로 적용됩니다.

안특징주의
M1 둥근 입력바지금 구조 유지 + 알약형 입력창 + 캐릭터 아바타/플레이스홀더(말버릇)변경 최소, 30분이면 끝
M2 메신저 로그 추천내가 보낸 메시지 + Claude 응답 요약이 말풍선으로 쌓임. 터미널은 그대로 위에 유지터미널 출력 파싱이 필요 — 이미 있는 세션 뷰어 로직 재사용 가능
M3 카톡형 전체터미널을 접고 대화만 보는 모드. 우측=나(노랑), 좌측=캐릭터가장 큼. 뷰어 패널을 캐릭터 스킨으로 감싸는 형태로 별도 작업 권장

4 캐릭터별 테마 정의

각 캐릭터의 실제 설정(색·성격·말버릇)에서 팔레트와 문구를 뽑았습니다. 마스코트는 원저작물 복제가 아닌 단순 도형으로 재해석한 아이콘입니다(개인용/배포 리스크 회피).
