캐릭터 테마 & 폰트 개편 — 시안 v2 (실제 캐릭터 이미지)

v1 피드백 반영: 마스코트를 직접 그리지 않고 실제 캐릭터 이미지를 쓰는 구조로 바꿨습니다. 커서도 사용자가 원하는 이미지로 직접 교체할 수 있게 설계했습니다. 입력창은 고르신 M2 / M3 두 안만 남겨 자세히 그렸습니다.

0 캐릭터 이미지를 어디에 두는가

핵심 결정: 이미지는 저장소(git)와 설치파일(.exe) 바깥, 사용자 PC 로컬 폴더에 둡니다.

먼저 확인하실 것 — 이 저장소는 GitHub에서 public(전체 공개) 이고 릴리즈로 Setup.exe 를 배포 중입니다. (CLAUDE.md 에는 "개인 비공개"라고 적혀 있는데 실제 설정은 public 입니다.) 캐릭터 공식 이미지를 저장소에 커밋하거나 설치파일에 넣으면 재배포가 되어 저작권 문제가 생깁니다. 그래서 앱은 이미지를 읽기만 하고, 파일은 각자 PC에만 두는 구조로 설계했습니다 — 개인 사용에는 아무 제약이 없습니다.

폴더 구조 (기존 상태 폴더 재사용)

~/.claude-terminal-hub/ ├─ state.json ← 지금도 쓰는 세션/프로필 저장 파일 └─ theme-assets/ ← [신규] 캐릭터 이미지 폴더 ├─ hachiware.webp ← 테마 키와 같은 이름이면 자동 인식 ├─ usagi.webp ├─ momonga.webp ├─ rakko.webp ├─ flurry.png ├─ rasher.png ├─ marshal.png └─ cursor-custom.png ← [선택] 커서 전용 이미지
항목동작
서버 라우트 신규app.use('/theme-assets', express.static(~/.claude-terminal-hub/theme-assets)) — 한 줄
이미지 넣는 법① 폴더에 직접 복사 ② 앱 안에서 드래그&드롭 / 파일 선택 → 자동 저장 (아래 1번에서 미리 써볼 수 있음)
git / 설치파일사용자 홈 폴더라 애초에 포함 안 됨. .gitignore 에도 명시
이미지가 없을 때테마는 색상만 적용되고 아이콘 자리는 숨김(Lv1과 동일) — 앱이 깨지지 않음

아래 미리보기에는 이 PC의 theme-assets 폴더에 받아둔 이미지가 그대로 표시됩니다.

3 입력창 — M2 / M3 상세

위에서 고른 캐릭터·색이 그대로 적용됩니다.

M2. 메신저 로그 터미널 유지

터미널은 위에 그대로 두고, 아래 컴포즈가 대화 로그로 확장됩니다. 도구 실행은 회색 줄로 접혀서 표시.

  • 터미널을 보면서 대화 맥락도 같이 확인
  • 기존 세션 뷰어 파싱 로직 재사용 가능
  • 패널 높이를 먹음 → 접기/펴기 필요

M3. 카톡형 전체 터미널 접기

터미널을 접고 대화만 보는 모드. 상단에 캐릭터 이름·상태, 좌측 캐릭터 / 우측 나.

  • 가장 메신저다움 — 진행 상황 훑어보기 좋음
  • 터미널 토글 버튼으로 즉시 복귀
  • 세부 출력이 안 보임 → 긴 작업엔 M2가 유리
제안 — 배타 선택 대신 같은 컴포즈의 2가지 표시 모드로 만들 수 있습니다. 헤더 토글 하나로 M2 ⇄ M3 전환.
